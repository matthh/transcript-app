## Critical

### C-1 · `/api/search` accepts arbitrary BM25 queries without auth — carry-over
**File:** `src/app/api/search/route.ts`
**Finding:** The BM25 full-text search endpoint is unauthenticated and
accepts a `q` parameter that is passed directly to the inverted-index
lookup. Any unauthenticated client can enumerate the transcript corpus.
**Status:** Upstream issue — not fixable in this fork.

### C-2 · `/api/transcripts/[id]` streams raw transcript without auth — carry-over
**File:** `src/app/api/transcripts/[id]/route.ts`
**Finding:** Full transcript text is served to any client with the episode
ID. No session or API-key check.
**Status:** Upstream issue — not fixable in this fork.

### C-3 · `/api/embed` computes and returns vector embeddings without auth — carry-over
**File:** `src/app/api/embed/route.ts`
**Finding:** The embedding endpoint incurs Anthropic API cost on every call
with no authentication. An external party can use this as a free embedding
service.
**Status:** Upstream issue — not fixable in this fork.

### C-4 · `/api/admin` routes gated only by `X-Admin-Secret` header — carry-over
**File:** `src/app/api/admin/route.ts`
**Finding:** Admin access is a single shared static secret passed as a
header. No IP allowlist, no session binding, no TOTP. The secret is also
stored in Vercel environment variables alongside other project secrets —
compromise of any secret leaks them all.
**Status:** Upstream issue — not fixable in this fork.

### C-5 · `claude-sonnet-4-20250514` and `claude-3-haiku-20240307` model IDs are retired — carry-over
**Files:** `src/lib/claude.ts`, `src/lib/search-tuning.ts`
**Finding:** `claude-sonnet-4-20250514` is past its announced retirement
date and returns HTTP 404 at inference time. `claude-3-haiku-20240307`
(used as the fast search-tuning variant in `search-tuning.ts`) is a Claude
3 model — retired in favour of Haiku 4.5. Both silently break AI features
in production.
**Status:** Upstream issue — not fixable in this fork.

### C-6 · Vector search index rebuilt on every `/api/search` request — carry-over
**File:** `src/lib/vector-store.ts`
**Finding:** The in-memory vector store is re-populated from raw embeddings
on every search request. With a large corpus this is O(N) work per query
and causes prohibitive latency (seconds) and memory churn.
**Status:** Upstream issue — not fixable in this fork.

## High

### H-1 · BM25 index rebuilt on every search — carry-over
**File:** `src/lib/search.ts`
**Finding:** The inverted index is constructed from the transcript corpus on
every call to the search endpoint. With hundreds of transcripts this adds
significant per-request latency and CPU cost.
**Status:** Upstream issue — not fixable in this fork.

### H-2 · Vector search results not deduplicated before reranking — carry-over
**File:** `src/lib/vector-store.ts`
**Finding:** The same passage can appear in the result set multiple times if
it matches multiple query vectors. The reranker then wastes budget on
duplicates, degrading result quality.
**Status:** Upstream issue — not fixable in this fork.

### H-3 · HTML injection in email templates — carry-over
**File:** `src/lib/email.ts`
**Finding:** Episode titles and guest names are interpolated directly into
HTML email bodies without escaping. A title containing `<script>` or a
crafted guest name could inject HTML into the email.
**Status:** Upstream issue — not fixable in this fork.

## Medium

### M-1 · `process.env` accessed at module scope — carry-over
**File:** `src/lib/claude.ts`
**Finding:** `new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY })` is
called at module import time. In a serverless context, the env var may not
be populated at module load.
**Status:** Upstream issue — not fixable in this fork.

### M-2 · No request-body size limit on `/api/transcripts` POST — carry-over
**File:** `src/app/api/transcripts/route.ts`
**Finding:** Large transcript uploads are accepted without a size cap.
**Status:** Upstream issue — not fixable in this fork.

### M-3 · Search endpoint has no pagination — carry-over
**File:** `src/app/api/search/route.ts`
**Finding:** All matching results are returned in a single response.
**Status:** Upstream issue — not fixable in this fork.

### M-4 · Embeddings stored in `localStorage` — carry-over
**File:** `src/hooks/useSearch.ts`
**Finding:** Vector embeddings (typically several hundred KB) are persisted
to `localStorage`. `localStorage` has a 5 MB per-origin limit; a full corpus
cache risks a `QuotaExceededError` crash.
**Status:** Upstream issue — not fixable in this fork.

### M-5 · No error boundary around search UI — carry-over
**File:** `src/components/Search.tsx`
**Finding:** A failed embedding or search throws to the root, crashing the
page. No `ErrorBoundary` isolates the search widget.
**Status:** Upstream issue — not fixable in this fork.

### M-6 · `useEffect` dependency arrays are incomplete throughout — carry-over
**Files:** Multiple component files
**Finding:** Several `useEffect` hooks are missing dependencies, meaning
stale closures capture outdated state. The ESLint rule is suppressed.
**Status:** Upstream issue — not fixable in this fork.

## Low

### L-1 · No loading skeleton for search results — carry-over
**File:** `src/components/Search.tsx`
**Finding:** The search UI shows no loading indicator while the embedding
and BM25 search run. Users see a blank results area during a potentially
multi-second operation.
**Status:** Upstream issue — not fixable in this fork.

### L-2 · `data/` directory grows unboundedly — carry-over
**File:** `data/`
**Finding:** Episode data files accumulate with no archival or pruning
strategy. The directory will grow linearly with the show's episode count.
**Status:** Upstream issue — not fixable in this fork.

### L-3 · No test suite — carry-over
**Status:** No tests exist in this fork either (upstream has none).
**Status:** Upstream issue — not fixable in this fork.

### L-4 · `transcripts/` directory committed to git — carry-over
**File:** `transcripts/`
**Finding:** Full transcript text files are committed to the repository,
bloating git history. As the show grows, clone time increases linearly.
**Status:** Upstream issue — not fixable in this fork.
