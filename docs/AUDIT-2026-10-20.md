## SECURITY

### Critical

#### SC-1 · `PUT` and `DELETE /api/transcripts/[episode]` are unauthenticated (T-19)

`src/app/api/transcripts/[episode]/route.ts` — no auth guard on write/delete paths. Any internet
caller can overwrite or wipe production transcripts from Vercel Blob. **Fix:** add bearer-token
or session auth before accepting PUT/DELETE.

#### SC-2 · `POST /api/transcript-rename` is unauthenticated (T-20)

`src/app/api/transcript-rename/route.ts` — renames transcript Blob entries with no auth. **Fix:**
same bearer-token pattern as `/api/external/search`.

#### SC-3 · `POST /api/rebuild` is unauthenticated (T-3)

`src/app/api/rebuild/route.ts:3` — triggers GitHub Actions (`GITHUB_PAT`) with no auth guard. Any
caller can spam CI runs. **Fix:** guard with `CRON_SECRET` or a dedicated rebuild token.

#### SC-4 · AssemblyAI webhook has no HMAC signature verification (T-6)

`src/app/api/transcribe/webhook/route.ts` — accepts any POST with a matching `transcript_id`.
**Fix:** verify `x-assemblyai-signature` header per AssemblyAI docs.

### High

#### SH-1 · HTML injection in email templates (T-14, T-21)

`src/app/api/transcription-error/route.ts` and `src/app/api/feedback/route.ts` interpolate
user-supplied strings directly into HTML email bodies without escaping. **Fix:** escape all
interpolated values with an HTML-entity encoder before inserting into the template.

#### SH-2 · PodReview password comparison is not timing-safe (T-4)

`src/lib/podreview-auth.ts` — uses `===` string comparison. **Fix:** replace with
`crypto.timingSafeEqual()`.

#### SH-3 · `POST /api/eval/generate` is unauthenticated, no rate limit (T-24)

`src/app/api/eval/generate/route.ts` — fires Anthropic API calls with no auth or cost cap.
**Fix:** add bearer-token check using `PODREVIEW_PASSWORD` or a dedicated env var.

#### SH-4 · Model IDs at elevated retirement risk — escalation of T-23

`src/lib/routing-policy.ts:45,109` — `DEEP_SYNTHESIS_MODEL` and `AGENT_SEARCH_MODEL` are both
`'claude-sonnet-4-20250514'`. As of 2026-10-20 this model ID is approximately 17 months old.
The companion `escape-hatch-explore` CLAUDE.md records that `claude-sonnet-4-20250514` previously
sat in that repo for a month past its retirement, causing silent 404s in deep synthesis and agent
search. The risk of the same retirement having occurred here — and being silently swallowed in
production — is materially higher than at last review. **Immediate action:** verify the model ID
is still live against the Anthropic API (no credits required — a models list endpoint returns 404
for retired IDs). Upgrade to `claude-sonnet-5-5` or the current stable Sonnet alias.

The fast-variant model `claude-3-haiku-20240307` (used when `INTERPRETIVE_FAST_MODEL` is unset,
`src/lib/search-tuning.ts`) is similarly aged (March 2024). Upgrade to `claude-haiku-5-5`.

### Medium

#### SM-1 · `/api/debug` unauthenticated, leaks internal metadata (T-2)

`src/app/api/debug/route.ts` — no auth, returns full query classification and metadata results.
Hardcoded `filmFilter = 'close encounters'` is a debugging artifact. **Fix:** remove the route or
protect with the `PODREVIEW_PASSWORD` bearer pattern.

#### SM-2 · Feedback and eval data stored in public Blobs (T-8, T-10)

`lib/query-logger.ts`, `api/feedback`, `api/cleanup-feedback`, `api/eval/feedback` write to
Vercel Blob with `access: 'public'`. User query text and names are world-readable.
**Fix:** switch to `access: 'private'` and serve via signed URLs.

#### SM-3 · Analytics endpoints unauthenticated (T-25, T-26)

`/api/analytics/use-cases` and `/api/eval/results` expose full query-log and eval data with no
auth. **Fix:** add bearer-token check before returning log data.

#### SM-4 · In-memory rate limiting is per-Lambda-instance (T-1)

`src/lib/external-rate-limit.ts` — counters reset on Lambda recycle. Under multi-instance
deployments, rate limits can be exceeded. **Fix:** Upstash Redis or Vercel KV.

#### SM-5 · TMDB API key passed as query-string parameter (T-7)

`GET /api/tilda`, `GET /api/kev`, TMDB enrichment scripts — key appears in server logs/traces.
**Fix:** use bearer token auth (`Authorization: Bearer <key>`) per TMDB v4 API docs.

### Low

#### SL-1 · Google Sheets ID hardcoded (T-11)

`src/app/api/podreview/update-pdc/route.ts` — `SHEET_ID` is a string literal. Move to env var.

#### SL-2 · GitHub repo name hardcoded (T-12)

`src/app/api/rebuild/route.ts:3` — `GITHUB_REPO = 'jbennygold/transcript-app'`. Move to env var.

## PERFORMANCE

### High

#### PH-1 · Agent search loads all 300+ transcripts into Lambda memory (T-18)

`src/lib/agent-search.ts` — full transcript corpus loaded into memory on first agent call.
Causes cold-start latency spikes and high memory pressure. **Fix:** lazy-load transcripts on
demand per tool invocation.

### Medium

#### PM-1 · `/api/transcripts` and `/api/speakers` are O(N) serial Blob waterfalls (T-15, T-22)

Both endpoints fetch each transcript individually in a serial loop with no caching.
**Fix:** parallelise with `Promise.all` and add an in-memory TTL cache.

#### PM-2 · Vector store, BM25 index, and playlist data cached indefinitely (T-9, T-17)

Module-level caches never refresh within a warm Lambda instance, serving stale data after
re-ingest. **Fix:** add a TTL (e.g. 15 minutes) or a generation counter to force refresh.

## MAINTAINABILITY

### High

#### MH-1 · `check:models` script referenced in docs but does not exist (T-27)

`package.json` has no `check:models` script. Multiple audit docs and ARCHITECTURE.md describe
running it to verify model IDs against the live API. It cannot be run.
**Fix:** implement a simple script (e.g. `scripts/check-models.ts`) that calls the Anthropic
models list API and exits non-zero if any ID in `routing-policy.ts` is absent from the list.
Add it to `package.json` scripts and to the CI workflow.

#### MH-2 · `next: "latest"` not pinned in package.json

`package.json:38` — `"next": "latest"` means any `npm install` can pull in a breaking Next.js
major release without a corresponding code change. The upstream repo is not maintained here, so
a silent major upgrade could break the build or runtime in unpredictable ways.
**Fix:** pin to the exact version currently installed (check `package-lock.json` or
`node_modules/next/package.json`) and update deliberately.

### Medium

#### MM-1 · Anthropic client instantiated outside singleton in three files (T-13)

`src/lib/share-summary.ts`, `src/app/api/cleanup-transcript/route.ts`, and
`src/app/api/detect-samples/route.ts` call `new Anthropic()` directly instead of using
`getAnthropic()` from `lib/claude.ts`. Creates extra client instances per cold start.
**Fix:** import and use `getAnthropic()` from `lib/claude.ts` in all three files.

#### MM-2 · ChromaDB dependency retained for superseded local-dev scripts (T-deprecated)

`package.json` still depends on `chromadb ^1.9.2` though the vector store has moved to
Vercel Blob. The only remaining users are local dev scripts that have not been deleted.
**Fix:** delete the dead scripts and remove the `chromadb` dependency.

#### MM-3 · PodReview submit/update-pdc split is confusing (T-5)

`POST /api/podreview/submit` only logs to console; `POST /api/podreview/update-pdc` does the
actual sheet write. No UI distinction. **Fix:** consolidate into a single endpoint or add clear
UI labels distinguishing the two actions.
