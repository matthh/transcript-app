## SECURITY

### Critical

#### SC-1 · `PUT` and `DELETE /api/transcripts/[episode]` are unauthenticated (T-19)

`src/app/api/transcripts/[episode]/route.ts` — no auth guard on write/delete paths. Any
internet caller can overwrite or wipe production transcripts from Vercel Blob. **Fix:** add
bearer-token or session auth before accepting PUT/DELETE.

#### SC-2 · `POST /api/transcript-rename` is unauthenticated (T-20)

`src/app/api/transcript-rename/route.ts` — renames transcript Blob entries with no auth.
**Fix:** same bearer-token pattern as `/api/external/search`.

#### SC-3 · `POST /api/rebuild` is unauthenticated (T-3)

`src/app/api/rebuild/route.ts:3` — triggers GitHub Actions (`GITHUB_PAT`) with no auth guard.
Any caller can spam CI runs. **Fix:** guard with `CRON_SECRET` or a dedicated rebuild token.

#### SC-4 · AssemblyAI webhook has no HMAC signature verification (T-6)

`src/app/api/transcribe/webhook/route.ts` — accepts any POST with a matching `transcript_id`.
**Fix:** verify `x-assemblyai-signature` header per AssemblyAI docs.

### High

#### SH-1 · HTML injection in email templates (T-14, T-21)

`src/app/api/transcription-error/route.ts` and `src/app/api/feedback/route.ts` interpolate
user-supplied strings directly into HTML email bodies without escaping. **Fix:** escape all
interpolated values with an HTML-entity encoder before inserting into the template.

#### SH-2 · PodReview password comparison is not timing-safe (T-4)

`src/lib/podreview-auth.ts` — uses `===` string comparison. **Fix:** replace with
`crypto.timingSafeEqual()`.

#### SH-3 · `POST /api/eval/generate` is unauthenticated, no rate limit (T-24)

`src/app/api/eval/generate/route.ts` — fires Anthropic API calls with no auth or cost cap.
**Fix:** add bearer-token check using `PODREVIEW_PASSWORD` or a dedicated env var.

#### SH-4 · Model IDs at critical retirement risk — **further escalation**

`src/lib/routing-policy.ts:45,109` — `DEEP_SYNTHESIS_MODEL` and `AGENT_SEARCH_MODEL` are
both `'claude-sonnet-4-20250514'`. As of 2026-10-27 this model ID is approximately **18 months
old**. The companion `escape-hatch-explore` CLAUDE.md explicitly records that
`claude-sonnet-4-20250514` previously sat in that repo for a month past its retirement, causing
**silent 404s in deep synthesis and agent search in production**. The same model ID remains in
this repo's `routing-policy.ts` and there has been no verification of its live status since the
last audit. The probability that this model ID is already retired — and that production deep
synthesis and agent search are silently failing — is now very high.

**Immediate action required:** call the Anthropic models list API to verify the model is still
live (no credits required), then upgrade to `claude-sonnet-5-5` or the current stable Sonnet
alias if the ID is retired or deprecated.

The fast-variant `claude-3-haiku-20240307` in `src/lib/search-tuning.ts` (used when
`INTERPRETIVE_FAST_MODEL` is unset) is now ~2.5 years old. Upgrade to `claude-haiku-5-5`.

## PERFORMANCE

### High

#### PH-1 · Agent search loads all 300+ transcripts into Lambda memory (T-18)

`src/lib/agent-search.ts` — full transcript corpus loaded into memory on first agent call.
Causes cold-start latency spikes and high memory pressure. **Fix:** lazy-load transcripts on
demand per tool invocation.

### Medium

#### PM-1 · `/api/transcripts` and `/api/speakers` are O(N) serial Blob waterfalls (T-15, T-22)

Both endpoints fetch each transcript individually in a serial loop with no caching.
**Fix:** parallelise with `Promise.all` and add an in-memory TTL cache.

#### PM-2 · Vector store, BM25 index, and playlist data cached indefinitely (T-9, T-17)

Module-level caches never refresh within a warm Lambda instance, serving stale data after
re-ingest. **Fix:** add a TTL (e.g. 15 minutes) or a generation counter to force refresh.

## MAINTAINABILITY

### High

#### MH-1 · `check:models` script referenced in docs but does not exist (T-27)

`package.json` has no `check:models` script. Multiple audit docs and ARCHITECTURE.md describe
running it to verify model IDs against the live API. It cannot be run. **Fix:** implement a
simple script (`scripts/check-models.ts`) that calls the Anthropic models list API and exits
non-zero if any ID in `routing-policy.ts` is absent. Add to `package.json` and CI workflow.

#### MH-2 · `next: "latest"` not pinned in `package.json` (line 38)

Any `npm install` can pull in a breaking Next.js major release. The upstream repo is not
actively maintained here so a silent major upgrade could break the build. **Fix:** pin to the
exact version in `package-lock.json`.

### Medium

#### MM-1 · Anthropic client instantiated outside singleton in three files (T-13)

`src/lib/share-summary.ts`, `src/app/api/cleanup-transcript/route.ts`, and
`src/app/api/detect-samples/route.ts` call `new Anthropic()` directly instead of using
`getAnthropic()` from `lib/claude.ts`. **Fix:** import and use `getAnthropic()` in all three.

#### MM-2 · ChromaDB dependency retained for superseded local-dev scripts

`package.json` still depends on `chromadb ^1.9.2` though the vector store has moved to Vercel
Blob. **Fix:** delete the dead scripts and remove the `chromadb` dependency.

#### MM-3 · PodReview submit/update-pdc split is confusing (T-5)

`POST /api/podreview/submit` only logs to console; `POST /api/podreview/update-pdc` does the
actual sheet write. **Fix:** consolidate or add clear UI labels distinguishing the two actions.

### Low

#### ML-1 · `/api/debug` unauthenticated, leaks internal metadata (T-2)

`src/app/api/debug/route.ts` — no auth, returns full query classification and metadata. Hardcoded
`filmFilter = 'close encounters'` debugging artifact. **Fix:** remove or protect with bearer token.

#### ML-2 · Feedback and eval data stored in public Blobs (T-8, T-10)

`lib/query-logger.ts` and feedback routes write to Vercel Blob with `access: 'public'`. User
query text and names are world-readable. **Fix:** switch to `access: 'private'`, serve via
signed URLs.

#### ML-3 · Analytics endpoints unauthenticated (T-25, T-26)

`/api/analytics/use-cases` and `/api/eval/results` expose full query-log and eval data with no
auth. **Fix:** add bearer-token check before returning log data.
